# 🎬 나만의 영화 아카이브 만들기

실습에서 만든 영화 아카이브를 바탕으로  
자신이 좋아하는 영화와 스타일을 반영하여 나만의 영화 아카이브로 확장해봅니다.

## 🛠️ 과제 목표

1. 자신이 좋아하는 영화 데이터를 추가하여 나만의 영화 아카이브 만들기
2. `next/font`를 활용하여 영화 상세페이지(`/movies/[id]`)에만 다른 폰트 적용하기
3. `next/image`를 활용하여 영화 상세페이지의 영화 포스터에 Image Optimization 적용하기
4. Code Splitting을 활용하여 관람평을 `dynamic()`으로 불러오기
5. `<Link>`를 활용하여 Header 수정하기
